> **一句话**  
> 不是「学写甲骨文 App」，而是：用 **辨形 → 对义 → 读一句卜辞** 三步，让玩家亲手摸到「刻在骨头上的字」和「古人为什么要问」。

---

## 0. 为什么做这款（产品逻辑）

现有五展品覆盖：

| 展品 | 感官/动作 |
|------|-----------|
| 节气 | 时序、物候、农事知识 |
| 山海 | 器物修复、图志 |
| 圣杯 | 3D 物理、仪式感 |
| 英歌 | 节奏、队形、表演 |
| 剪纸 | 折剪、吉语、纹样 |

**缺口：文字系统。** 甲骨文是中国最早系统文字之一，SEO 与文化辨识度都强，且玩法可做成「轻认知 + 轻操作」，和现有不撞车。

MVP 成功标准（体验层）：

1. 第一次打开 30 秒内知道「我要干什么」
2. 完成 1 局后能说出至少 1 个甲骨字形「像什么」
3. 愿意再开第二局或点进文化页
4. 护照上出现至少 1 张甲骨卡

---

## 1. 体验支柱（不可破）

1. **字是主角，不是皮肤**  
   每个互动必须绑定真实（或学界通识）字形与义项，禁止纯装饰用字。
2. **先辨形，再记义**  
   玩家先「看出像什么」，再「知道是什么字」——符合甲骨「近取诸身、远取诸物」。
3. **卜辞是情境，不是试卷**  
   短句卜辞提供「古人在问什么」的故事感；不考商王世系、不考断代。
4. **克制 AI 味与游戏厅感**  
   无连击特效墙、无金币、无体力；结果页用「契刻感」与一句文化说明收束。
5. **史证语气**  
   用「通识认为」「常见于教材与图录」；不宣称本站复原某馆藏真片。

## 2. MVP 范围（做什么 / 不做什么）

### 2.1 做（Must）

| 模块 | 说明 |
|------|------|
| 主玩法 A：**辨形配对** | 甲骨字形 ↔ 现代汉字（或关键词义） |
| 主玩法 B：**契意三选一** | 给出字形 + 简图暗示，选正确义项 |
| 主玩法 C：**卜辞填空**（轻） | 一句短卜辞缺 1 字，从 3 个甲骨形里选 |
| 字库 | **24 字**（与节气 24 对称，好记） |
| 图鉴 | 已见过的字可回看：形、义、一句话、来源备注 |
| 首局引导 | FirstPlayGuide 3 步 |
| 本地进度 | 见过的字、通关模式、最佳表现 |
| 护照 3–4 卡 | 见下文 |
| 文化 hub | `/culture/jiagu/` 1 hub + 2–3 topic |
| 埋点 | 沿用六事件 |

### 2.2 不做（MVP 砍掉）

- 手写/笔画临摹（触控精度与实现成本高）
- 全片缀合拼图（学术门槛高，留 V1.1）
- 商代地图大世界、角色养成
- 语音朗读、多语言
- 用户上传拓片识别
- 超过 24 字的大图鉴（V1 再扩到 60）

## 3. 核心玩法 GDD

### 3.1 信息架构（界面流）

```
首页壳（GameChrome）
├─ 开始契刻（默认进「今日三契」综合局）
├─ 辨形（模式 A）
├─ 契意（模式 B）
├─ 卜辞（模式 C）
├─ 字图鉴
└─ 文化导读 → /culture/jiagu/
```

**「今日三契」**（推荐默认局，降低选择瘫痪）：

1. 辨形 × 4 题  
2. 契意 × 3 题  
3. 卜辞 × 1 题  
4. 结果页：本局新识字 + 一句文化收束 + 护照进度提示  

约 **3–5 分钟** 一局。

### 3.2 模式 A · 辨形配对（Match）

**玩家目标**：把甲骨字形卡与现代汉字卡配成对。

**规则**：

- 一局 4 对（8 张卡，2×4 或自由翻牌）
- 一次可翻 2 张；对则锁定，错则盖回
- 记 **步数**（越少越好），不限时（文化展气质，不压迫）
- 首次配对成功的字写入「已识」

**教学点**：形与义的象似性（日像日、山像山、水像水波）。

**失败友好**：可「看提示」一次（高亮一对），扣表现分但不锁进度。

### 3.3 模式 B · 契意三选一（Quiz）

**玩家目标**：看甲骨形 + 短描述，选正确义项。

**题目结构**：

```
[甲骨字形 大图]
题干：这个字，通识认为画的是什么？
A. …
B. …
C. …
选后揭晓：正确义 + 一句 lore + 「像什么」的点破
```

- 一局 3–5 题，题库从 24 字抽取，已错题权重略升
- 不倒计时

**教学点**：从「像」到「词义」（如「佳/鸟」作语助在卜辞里的用法——MVP 可只做本义，引申义放图鉴折叠）。

### 3.4 模式 C · 卜辞填空（Fill）

**玩家目标**：读懂一句极短卜辞在问什么，并补上缺字。

**示例（示意，定稿前需文献核对）**：

> 「贞：□ 雨？」  
> （问：会下雨吗？）  
> 选项三形：雨 / 日 / 狩

- 一局 1–2 句（MVP 总量 8–12 句模板即可）
- 选对后展开：**白话翻译** + **古人为什么问这个**（农事、出行、祭祀——各 1 句）

**教学点**：甲骨文首先是「问事的工具」，不是书法展览。

### 3.5 难度曲线（MVP 单档 + 软进阶）

| 阶段 | 字范围 | 说明 |
|------|--------|------|
| 入门 | 8 个象形极显字（日日月山水木人犬） | 首局必从这里抽 |
| 进阶 | +8 个稍抽象（上下大中田目） | 识字 ≥6 解锁 |
| 深入 | +8 个（雨、卜、贞、王、狩等） | 识字 ≥12 解锁 |

无「失败重开惩罚」；只有题池变宽。

## 4. 内容规格（24 字字库）

### 4.1 字段（每字一张 Content Card）

| 字段 | 说明 |
|------|------|
| `id` | 稳定英文/拼音键，如 `ri` / `yu-rain` |
| `modern` | 现代汉字 |
| `gloss` | 2–6 字义项 |
| `shapeHint` | 「像什么」一句话 |
| `lore` | 40–80 字文化说明 |
| `glyph` | MVP：**SVG 线描**（自制简化甲骨形，非拓片扫描版权风险） |
| `tier` | 1 入门 / 2 进阶 / 3 深入 |
| `tags` | nature / body / action / ritual … |
| `sourcesNote` | 「据通识教材与公开图录归纳，字形为示意」 |

### 4.2 MVP 候选 24 字（可微调）

**Tier 1（象形显）**  
日、月、山、水、木、人、女、犬  

**Tier 2**  
上、下、大、中、田、目、口、火  

**Tier 3（卜辞高频/文化锚点）**  
雨、卜、贞、王、狩、禾、羊、车  

> 定稿前做一次 **字形示意合规检查**：SVG 为教学示意，不临摹单一有版权的美术字体文件。

### 4.3 卜辞模板（8–12 条）

结构固定，降低写作成本：

```
贞：[事件]？
事件 ∈ {雨, 晴, 狩有获, 出入无咎, …}
```

每条：`oracleText` / `blankId` / `options[3]` / `vernacular` / `whyAsked`

## 5. 文化护照卡（3–4 张）

| 卡 id | 名 | 获取条件（派生自 progress） | 设计意图 |
|-------|----|------------------------------|----------|
| `jiagu-first-glyph` | 初识契文 | 任意模式首次答对 1 字 | 第一局必得 |
| `jiagu-eight` | 八字入门 | 已识字 ≥ 8 | 推第二局 |
| `jiagu-divination` | 问雨之契 | 完成 ≥1 次卜辞填空 | 理解「问事」 |
| `jiagu-codex` | 契册初成 | 图鉴读完 ≥12 字详情 或 已识 ≥16 | 深度向（可 MVP 先做 3 张，第 4 张可选） |

护照仍 **只读派生**，不新建第二套存档真相。

## 6. 进度与存档

```ts
interface JiaguProgress {
  version: 1;
  /** 已正确辨识过的字 id */
  knownIds: string[];
  /** 打开过图鉴详情的字 */
  readIds: string[];
  /** 各模式完成次数 */
  runs: { match: number; sense: number; omen: number; daily: number };
  /** 辨形最佳（最少步数，按题量归一或只记 daily） */
  bestMatchMoves: number | null;
  /** 累计正确题数（埋点/成就用） */
  correctTotal: number;
}
```

键名：`rex-game:jiaguwen:progress:v1`

## 9. 学习目标（给「玩中学」验收用）

玩完 2 局后，玩家应能：

1. 指出至少 3 个字「为什么长这样」（日/山/水类）
2. 说出甲骨文常见用途之一：**占问未来之事**
3. 区分「字形示意」与「博物馆拓片真迹」

---

## 10. 风险与对策

| 风险 | 对策 |
|------|------|
| 字形版权/临摹争议 | 自制几何化示意 SVG + 来源声明 |
| 学术表述过满 | 每字只 1 个主义项；争论点不进主路径 |
| 变成识字 flashcard | 用卜辞情境与「像什么」叙事绑住 |
| 内容写作慢 | 先锁 24 字表，文案可迭代；程序用 placeholder lore |
| 与节气 quiz 同质 | 辨形以 **视觉字形** 为主，不是纯文字题 |

   - B. 字与卜：甲骨文
