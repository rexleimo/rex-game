## 0. 定位（标题与宣传语，写死）

**《山海问兽》——一部可以玩的《山海经·南山经》：以杖问兽，以名定形。**

- 类型标签：**2.5D 横视角实时动作 RPG**（街机手感 · 伊苏3 式跳跃挥杖 · 巫师3 式委托-调查-遭遇结构）
- 时长承诺：**主线 8.5h + 支线/收集 ≥3h，通关口径总时长 11h±**
- 平台：浏览器（桌面键鼠优先 + 触屏适配），进度本地
- 三不做：**不做答题弹窗、不做 3D、不做无战斗的剧情墙**

## 1. 世界观：《山海经》→ 修仙设定的转化（回答「怎么转」）

### 1.1 转化原则

《山海经》表面上是「志怪地理」，骨架其实是一套**上古巫觋世界观**，它自带修仙所需的全部零件，不需要借萧鼎/凡人流的体系：

| 《山海经》原生概念 | 本作设定功能 | 修仙学名的对应 |
| --- | --- | --- |
| 「其名曰狌狌」（命名） | **真名之力**：名可定形、锁变、醒神。吞名→失形→化瘴 | 「法号/真灵」 |
| 「其祠之礼…」（祭祀） | **礼制**：祭则山安、失祀则瘴生。玩家以祭收尾每山 | 「宗门仪轨/气运」 |
| 「佩之不迷」「食之不饥」 | **佩饰=装备，食=丹膳养成**（逐字来自原文，天然锚定） | 「法宝/丹药」 |
| 「冬死而夏生」（鯥） | **化**：兽为山川之气所聚，气聚成形、气散归山——生死只是「一蛰」 | 「兵解/尸解」 |
| 「不可以上」（猿翼/亶爰） | **禁地门禁**：瘴浓之地以礼与识破开路 | 「秘境」 |
| 鸟身龙首之神 | **山神=脉之意志**，失名则形散——终章 boss 与祭典对象 | 「地祇」 |
| 人面鱼（赤鱬）、自为牝牡（类） | 形异而性全，「异类修仙」的天然样本 | 「妖修」 |

> 一句话：**本作里的「修仙」不是人升天，是「问名」——人记山名、山养人形；忘了名字，神也会变成瘴。** 玩家的力量三级来源：礼（祭仪buff）、名（识破/收服）、药（佩食炼制），全部有原文出处。
> 演绎标注：无名客、山望、问名体系为游戏化原创，图鉴脚注统一声明（沿用站点合规做法）。

### 1.2 三层世界观（供文案与美术共用）

1. **地表层**：鹊山首脉十山，村民以采药、渔盐、琢玉为生——烟火气（GTA 的「城」）。
2. **气化层**：山川一气，祭礼是「调音」；失祀→气滞→瘴→兽狂→人退——一条因果链跑遍全脉。
3. **名相层**：名是形之锚。山神无名则散，兽被夺名则狂，人忘其名则迷。反派吞名，主角「问名回形」。

### 1.3 玩家动机链（全程回答「我为什么要打」）

```
找师父（个人执念，序章立） 
 → 平息各山之瘴（区域目标，委托驱动） 
   → 查清瘴源=失祀，失祀=名字被吞（世界谜团，一幕末抛钩） 
     → 从无名客口中得知：师父「还在问」——他还活着，但被吞名吊着（二幕动机加压） 
       → 终章：以一路问回的真名破吞名者，救师，补祭，由你写下第十山之名（主题闭环）
```

**拍板点**：转化框架与动机链是否满意；不想要「修仙味」用词可全部降级为「巫礼味」（改词不改系统）。

## 3. 玩法循环

### 3.1 循环图

```
分钟环  跑图探索 → 遭遇战(打/识/闪) → 采获(药材/残页/齿痕) → 危机回祠( checkpoint )
小时环  闻(委托) → 迹(勘查现场,拼线索) → 备(回藏馆炼制/配佩饰) → 遇(精英/boss) → 决(杀/驯/祭)
整体环  十山卷轴推进 → 藏馆枢纽(家) → 山望改变村民线与瘴情 → 终章祭山 → 巡山周回
```

- 「迹」拍是巫师式查案：场景内线索点（爪迹/折桂/湿印/半句残页）拼合后**才**显露 boss 巢——文案纲要 §5 的产物，无答题。
- 「备」拍回藏馆：炼佩饰、喂同行兽、接委托——博物馆内容在此**全量保留且有用**（见 §5.1）。

### 3.2 目标系统（玩家永远知道下一步干什么）

HUD 左上「行卷」面板：当前山 + 五拍进度 + 委托角标；界碑/祠座为 fast-travel 与复活点（GTA 逻辑）。无目标时兜底文案恒指藏馆。

### 3.3 养成线（与战斗绑定）

| 线 | 来源 | 上限 |
| --- | --- | --- |
| 杖式 3 门（采药杖/掣电杖/祭礼杖） | 每门 4 段招式升级，材料=各山「多X」产物 | 一幕/二幕/三幕各开一门 |
| 佩饰 9（皆「佩之…」原文） | 石叔/婆婆炼制，槽×3 | Build 差异（不迷=免迷、不畏=免疫恐惧溃逃…） |
| 丹膳 6（皆「食之…」原文） | 祝余=续航、鯥脯=消肿…战前 buff | 3 格药囊 |
| 同行兽 13 | 收服获得，出战 3，主动技 1/被动 1（现有 kit 字段直接复用） | 亲密度解锁被动强化 |
| 山望（每山独立） | 驯>杀、护村民、清瘴源 | 影响委托台词/价格/夜袭复现 |

### 3.4 NPC 与拟人化分级（满足「肯定得有 NPC」）

| 级 | 定义 | 例 |
| --- | --- | --- |
| N1 人形 NPC | 全人形村民/匠人，委托与功能 | 阿果(委托板)、婆婆(丹)、石叔(佩)、珠娘(水路/终章)、老羊(青丘支线) |
| N2 拟人兽 NPC | 能言兽，**限 3 位**防串味：老白猿「王」(堂庭调停者)、类(亶爰智者)、九尾(青丘双面) | 文案纲要已配台词 |
| N3 兽形同行 | 收服后以行为演性格（图鉴小回放+战斗内反应喊话），不开口 | 13 兽 |
| N4 神形 | 鸟身龙首山神：无台词，以气象/祭效回应 | 终章 |

**拍板点**：N2 只开 3 位够不够「有 NPC 有人格化」？（再多会稀释《山海经》兽形原味。）

## 4. 战斗系统（M3 核心：实机、打击感、操作感）

### 4.0 设计基准

参照：**伊苏3 的跳跃挥杖 + 街机的接触威胁与波次压制 + 现代动作三件套（顿帧/前摇可读/架式破防）**。敌方全部为兽（无杂兵人形），招式由原文「性」轴推导——战斗即阅读。

### 4.1 操作（键鼠 / 触屏双版）

| 动作 | 键鼠 | 触屏 |
| --- | --- | --- |
| 移动/跳跃 | A D / W·Space（可爬窄壁，伊苏3 式） | 左摇杆 / 右上跳键 |
| 轻攻（三连段） | J | B1（后两段可转向） |
| 蓄力重击（破架式） | K（蓄 0.8s 满） | B2 长按 |
| 翻滚闪避（无敌帧） | L | B3 |
| **识破格挡**（弹反窗口） | I | B4 |
| 兽伴技 | 1/2/3 | 头像点按 |
| **命名收服**（条件满足时） | Q | 浮现大按钮 |

### 4.2 玩家状态机（12 态）

idle / run / jump(升·落) / climb / light1·2·3 / chargeHeavy / roll / parry / hurt / stagger / getup。
帧数（60fps，示意值，M1 原型调参）：轻1 前摇6/判定4/收招8；轻3 带 4px 位移；重击满蓄前摇 14、破架式×3；翻滚 20 帧/无敌 8–14；**弹反窗口 8 帧，成功=敌人踉跄 40 帧+识破+0.5 层**；受身 30 帧。

### 4.3 敌人系统

- **重量级三档**：轻兽（可打断、连段吃满）/ 凶兽（有架式条，削满=大硬直处决窗）/ 古兽＝精英与 boss（霸体，只能弹反或破架式，伊苏3 式「找招式的空当」）。
- **前摇可读铁律**：所有攻击有 24–40 帧预备动作 + 部位红闪 + 音效预备层；boss 每阶段一套「语汇」（4–6 招），阶段切换有演出。
- 13 兽招式表（每兽 3 招 1 预备 1 弱点，全部源自 `nature` 轴，示例）：

| 兽 | 招式（原文依据） | 弱点=识破提示 |
| --- | --- | --- |
| 狌狌 | 伏行突进／学步诱敌(仿玩家步声)／祠柱荡击 | 冲完必回头看祠门（它守的是门）——耳侧黑瘴即破绽 |
| 旋龟 | 玄甲冲撞(霸体)／虺尾抽打／音爆「如判木」 | 音爆后 30 帧张口僵直；弹反音爆=听·识破 |
| 鯥 | 冬蛰假死回满(战 2 次)／蛇尾横扫／哞音召唤同类 | 假死时不追打，行礼(按Q一次)→直接+1 层——「蛰伏非死」 |
| 九尾 | 婴啼惑(全屏倒转)／九尾轮扫／雾隐分身×3 | 分身无尾影；啼声以旋龟佩(不聋)或弹反破 |
| …其余 9 兽 | 同表推演，M1 文档附录展开 | |

### 4.4 打击感七件套（规格）

1. **顿帧**：命中 60–90ms（重击 120ms，处决 200ms）；2. **击退/浮空**：按重量级向量表；3. **震屏**：2–4px 随机向，重击加径向白闪 1 帧；4. **水墨命中粒子**（朱砂/石青双色，本作美术签名）；5. **音效分层**：武器层(杖风)+体层(闷/脆按兽壳毛)+环境混响按山；6. **受击 confirmed 镜头**：boss 登场/命名瞬间定帧水墨晕开；7. 伤害数字默认关（设置可开，研学向不弹数字更「入画」）。

### 4.5 山望与双轨结算

每场 boss 倒下后 10 秒抉择窗口：**「问名」(Q 收服) 或「了断」(杖杀取材)**。杀=材料×2、山望−、当夜村民线变化；驯=兽伴、山望+、瘴域次日缩小（地表贴图分层切换）。终章结算差分结局 2 个。

### 4.6 「问兽」实战化（取代答题的全部方案）

- 三层识破=**打出来/查出来，不二选一**：
  - **形**：目睹并存活该兽每个招式组 ≥1 次，或弹反成功 1 次；
  - **声**：在它的「声兆」阶段完成弹反/打断（每兽一个音频 signature——「其音如判木」就是听音辨招）；
  - **性**：「迹」拍收集的现场线索 + 特定行为触发（如鯥假死时行礼、狌狌不追时停手——**慈悲即情报**）。
- 层齐 + 血量<25% → 大按钮「问名」→ 喝真名演出（§文案纲要 7.2）→ 收服。
- 原文知识从「考点」变成「机制说明书」：**读过图鉴的人少挨打**——藏馆回访有真用途，博物馆=武器库。

### 4.7 难度与辅助（浏览器展品必需）

简单/标准/动作辅助三档：辅助=弹反窗口×2、顿帧加强、识破获取减半要求；失败 3 次同一 boss 自动提示回藏馆刷委托升杖式（GTA 式「先去做点别的」）。

**拍板点**：键位/触屏布局；弹反是否为识破主通道（是→「声」层有门槛，辅助档兜底）；伤害数字默认关是否 OK。

## 5. 地图系统与摄像机

### 5.1 地图三层结构

```
L0 藏馆（博物馆·家）      L1 十山卷轴（世界图）       L2 各山（2.5D 横版关卡）
  室内 tile 地图：          横向展开的手卷：十山图位+     每山 3–6 屏横向连通+
  · 招摇山门(入口=开卷入戏)  进度印章、山望染色、          少量纵向爬升(伊苏3 爬壁)
  · 兽栏/炼制堂/丹膳房       齿痕玉牌陈列柜                祠座=存档/复活/fast-travel
  · 山海册(图鉴全文库)       快速旅行(已解锁山)             界碑刻本句原文(场景物件)
  · 巡山案(日常入口)         雾区=未解锁(瘴可视化)
```

- **博物馆保留方式**：序章后成为「家」；入山=在「招摇山门」展开图志（开卷转场，博物馆→世界的桥，不再开场直陈展柜）；原展品文案/卡片/引文一字不删，图鉴在藏馆可读。
- **十山卷轴图**即「要有地图」的答案：一张会长大的手卷，走过的山会「活」（山望上色），吞名的山留白——地图本身讲剧情。

### 5.2 各山关卡规格（例·招摇山）

| 屏 | 场景 | 玩法拍 |

## 6. 美术方向（怎么做美术，一页说死）

**风格合同**：「人在画中行」——**高精度 AI 青绿山水视差背景**（宣纸底纹，站点既有审美延续）之上，**16-bit 像素人形** + **水墨剪纸 rig 兽**。三层三工艺，各自扬长：背景省钱大气、像素人类动作干净、兽 rig 用最小动画量换最大表现（附肢/尾/羽独立 tween，九尾=九根独立尾）。

| 模块 | 规格 |
| --- | --- |
| 逻辑分辨率 | 960×540（16:9），CSS scale 适配，触屏 ≥1280 宽 |
| 调色 | 全局「黛青+赭石+朱砂+鎏金」四主色；每山一个色从原文推（杻阳=赤金/白金对照，青丘=青雘雾紫） |
| 角色 | 主角 48px 高、换杖式改杖不改人（省资源）；NPC 复用 LPC 骨架换色+发饰区分 |
| 兽 | 立绘部件切图 → Phaser 骨骼 tween；狂化=墨渍爬皮 shader、清醒=原色 |
| FX | 水墨（命中）、金屑（拾取金玉）、瘴=紫黑烟（与村火橙形成光源对比） |
| UI | 宣纸卷轴风沿用现有展品 CSS 变量；战斗 HUD 极简（血条=杖穗，识破=三枚印章） |
| 性能 | 目标中端手机 60fps：同屏精灵 ≤80、每层背景单图 ≤2048px、图集分山打包 |

## 7. 技术方案

| 项 | 决策 | 理由 |
| --- | --- | --- |
| 引擎 | **Phaser 3**（npm 依赖，动态 `ssr:false` 挂载，React 壳组件） | 街机/平台动作现成件全：Arcade Physics、Tilemap(Tiled JSON)、camera follow/deadzone/lerp、tween rig、粒子 |
| 代码分层（沿用仓库既有模式） | `src/games/shanhai-wenshou/core/*` **纯函数战斗数学与进度**（可单测）→ Phaser 只渲状态；`content/*` 数据不动结构只扩字段 | 保测试锚定；答题版核心可平滑迁移 |
| 存量复用 | `mountains.ts`(quote/plain/encounters/gathers)、`beasts.ts`(三轴=识破文案)、`items.ts`(佩食=装备丹膳)、`progression/save`、`core/daily`(巡山) **全保留**；`questions.ts` 退役为图鉴彩蛋 | 内容资产零浪费 |
| 存档 | `rex-game:wenshou:v1` → v2 迁移脚本（已通关者保留图鉴/山望，战斗纪录换算） | 不砸玩家进度 |
| 关卡工具 | Tiled（免费）编辑 tilemap 导出 JSON，入 `public/assets/shanhai-wenshou/maps/` | 地图系统可并行手填 |
| 测试 | 现有内容锚测试保持绿；新增：伤害/顿帧/状态机帧数/收服条件/daily 确定性 5 组单测（core 纯函数层） | 数值可回归 |
| 体积预算 | Phaser gzip ≈ 320KB + 素材按山懒加载（每山 ≤1.5MB） | 静态托管可接受 |
| 触屏 | 左摇杆+右侧 4 按钮 DOM 覆盖层（Phaser 外），设置可 remap | 展品场景必需 |
