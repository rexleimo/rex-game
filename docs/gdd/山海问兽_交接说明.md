## 2. 硬约束（不可违背）

- 《山海经·南山经》原文引文（`mountains.ts`/`beasts.ts` 的 `quote` 等）**逐字冻结**，有测试锚定；虚构演绎（狂化/山望/无名客等）一律带「游戏化演绎」标注
- 三不做：不做答题弹窗、不做 3D、不做无战斗剧情墙
- 博物馆与妖怪/图鉴内容**全量保留**：藏馆=游戏内枢纽（家），13 兽、引文、日常巡山均复用
- 引擎选型：Phaser 3 + React 壳（`ssr:false` 动态挂载）；战斗数值/进度保持 `core/*` 纯函数以便单测（沿用仓库既有分层）
- 旧答题版 demo **在 M1 灰盒验证通过前不删除**（`questions.ts` 退役为图鉴彩蛋）
- 存档键 `rex-game:wenshou:*` 需 v1→v2 迁移，不得砸掉已有进度
